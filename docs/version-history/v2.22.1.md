# v2.22.1

## Fixed

- **The review headline follows a dismissal (#1049).** The "Overall Risk | Findings" line used to keep the old risk and counts after a finding was dismissed. A hidden `headline-map` marker in each review body now lets a dismissal recompute the headline for carried-forward, inline, and body-level findings. A review posted before this release has no marker. For that review, a dismissed carried-forward finding lowers the counts and the risk reads `<risk> or lower`, until the next rescan.
- **A changed file that resolves outside the workspace is dropped for every analyzer (#1047).** A symlink, or a file under a symlinked directory, could point at a file elsewhere on the runner. v2.22.0 handled phpcs only. Now no analyzer or agent gets such a path.
- **A docs file no longer routes a mixed pull request to no review (#1039).** One `docs/` file next to real code used to give the whole PR no agents and no analyzers under this repository's docs route.

## Added

- **New policy route key `when.paths-all` (#1039).** The route matches only if every changed file matches at least one glob. Use it for a route that reduces review. `paths` is unchanged. See [Policy](../policy).
